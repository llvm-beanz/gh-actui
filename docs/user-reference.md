# User reference

## Usage

```console
gh actui <REPOSITORY>
```

`REPOSITORY` can be an HTTPS GitHub URL or an `OWNER/REPO` name.

The main table lists each workflow's name, state, and path. The highlighted row
is the current selection, and the table scrolls automatically as the selection
moves beyond the visible area.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| Down or `j` | Select the next workflow |
| Up or `k` | Select the previous workflow |
| Page Down | Move forward up to 10 workflows |
| Page Up | Move backward up to 10 workflows |
| Home | Select the first workflow |
| End | Select the last workflow |
| `q` or Escape | Exit |
